# Tree-Group

Tree-Group は、Google カレンダーで予定のゲストを設定するときに、メールアドレスを階層型グループから選択して追加するための Chrome 拡張機能です。

グループやメンバーをあらかじめ登録しておけば、部署・チームなどの構造に沿ってメンバーを選び、選択したメールアドレスを Google カレンダーのゲスト欄へ入力できます。

## 主な機能

- **階層型グループ管理**：グループの中にサブグループやメールアドレスを登録できます。
- **まとめてメンバー選択**：グループを選ぶと、その配下のメンバーをまとめて選択できます。個別のメンバーだけを選ぶこともできます。
- **ゲスト追加**：選択したメンバーを、Google カレンダーの予定作成・編集画面のゲスト欄に追加します。
- **登録済みゲストのコピー**：カレンダー画面に設定済みのゲストアドレスを取得し、クリップボードにコピーできます。登録名があるメンバーは、名前付きの形式でコピーできます。
- **グループの編集と移動**：グループの追加・編集・削除、ドラッグ＆ドロップによる階層変更、複数選択、Shift キーによる範囲選択に対応しています。
- **JSON インポート／エクスポート**：グループ設定をファイルに保存したり、別の環境へ読み込んだりできます。インポートは既存設定へのマージ方式です。
- **初期状態は折りたたみ**：ポップアップではグループを折りたたんだ状態で表示し、必要な階層を展開できます。

## インストール（開発版）

現在はリポジトリのソースコードから読み込む方法で利用できます。

1. このリポジトリを ZIP でダウンロードして展開するか、Git でクローンします。
2. Chrome で chrome://extensions/ を開きます。
3. 右上の **デベロッパー モード** を有効にします。
4. **パッケージ化されていない拡張機能を読み込む** をクリックします。
5. リポジトリ内の **src フォルダ**を選択します（リポジトリの最上位フォルダではありません）。
6. Google カレンダー（https://calendar.google.com/）を開き、ツールバーの Tree-Group アイコンから利用します。

ソースコードを更新した場合は、chrome://extensions/ で Tree-Group の再読み込みを行ってください。Google カレンダーのタブも再読み込みすると確実です。

## 使い方

### 1. グループとメンバーを登録する

1. ツールバーの Tree-Group アイコンをクリックします。
2. **グループ編集** を開きます。
3. **ルートグループ追加** で最上位のグループを作成します。
4. グループを選択し、名前と登録メンバーを編集して保存します。
5. 必要に応じてサブグループを作成し、グループ階層を整えます。

登録メンバーは、1 行に 1 件、またはカンマ区切りで入力できます。通常のメールアドレスに加えて、表示名を指定する形式にも対応しています。

例：

    alice@example.com
    "山田 太郎"<tanaka@example.com>

登録名はポップアップ上のメンバー表示や、ゲストアドレスのコピー時に使用されます。

### 2. Google カレンダーにゲストを追加する

1. Google カレンダーで予定の作成画面または編集画面を開きます。
2. Tree-Group のポップアップを開きます。
3. 追加したいグループ、サブグループ、または個別メンバーにチェックを入れます。
4. **選択メンバーをゲストに設定** をクリックします。

追加するには、Google カレンダーの予定編集画面が開いていて、ゲスト入力欄が利用できる必要があります。Google カレンダーの画面構成変更などにより、動作が変わる可能性があります。

### 3. 設定済みのゲストアドレスをコピーする

Google カレンダー上でゲストが設定されている状態でポップアップを開き、**画面のゲストアドレスをコピー** をクリックします。取得したアドレスがクリップボードにコピーされます。

### 4. 設定をバックアップ／移行する

グループ編集画面の **エクスポート (JSON)** で設定をファイルに保存できます。読み込む場合は **インポート (JSON)** を使用します。

インポートでは既存設定を丸ごと置き換えず、既存のグループにデータをマージします。同じグループ ID は統合され、メールアドレスの重複を避けながら追加します。インポート側に登録名がある場合は、その登録名が反映されます。ID の異なるグループは別のグループとして追加されるため、必要に応じて読み込み後に整理してください。

## データとプライバシー

- グループ名、階層、登録メンバーは、Chrome の chrome.storage.local に保存されます。
- この拡張機能には、設定を独自のサーバーへ送信する処理はありません。
- JSON エクスポートファイルには登録したメールアドレスやグループ情報が含まれる場合があります。共有・保管時は取り扱いに注意してください。
- ローカル保存は暗号化された専用保管庫を意味するものではありません。端末や Chrome プロファイルのアクセス管理にも注意してください。
- ゲスト追加機能は Google カレンダーのページ上で動作します。ゲストの招待・閲覧可否などは Google カレンダー側の仕様やアカウント設定に従います。
